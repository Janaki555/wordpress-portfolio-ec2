## 📌 Project Description
Hosted a dynamic WordPress portfolio website on AWS EC2 instance. Configured LAMP stack and deployed WordPress for personal blogging/portfolio.

## 🛠️ Tech Stack & AWS Services
- **AWS EC2** - t2.micro instance (Ubuntu)
- **Region:** ap-south-1 (Mumbai)
- **Web Server:** Apache2
- **Database:** MySQL
- **Platform:** WordPress (Bitnami / Manual Install)
- **Security Group:** Opened ports 22 (SSH), 80 (HTTP), 443 (HTTPS)

## ⚙️ What I Configured
1. Launched EC2 instance - t2.micro, Ubuntu 22.04
2. Connected via SSH using key pair
3. Installed Apache, MySQL, PHP (LAMP Stack)
4. Installed & Configured WordPress
5. Configured Security Group for web access
6. Assigned Elastic IP: 13.233.192.58
7. Made website live!
